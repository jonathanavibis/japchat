# JapChat

## 📖 Project Description (Bangla)

এই রিপোজিটরি হল **JapChat** – একটি জাপানি ভাষা চ্যাট এবং লার্নিং অ্যাপ্লিকেশন। অ্যাপের মূল লক্ষ্য হলো ব্যবহারকারীদের জাপানি কথোপকথন অনুশীলন করা, শব্দভান্ডার বৃদ্ধি করা এবং রিয়েল‑টাইমে চ্যাটের মাধ্যমে ফিডব্যাক পাওয়া।

### 🛠️ মূল বৈশিষ্ট্যগুলো
- **ইউজার অথেনটিকেশন** – Better Auth ব্যবহার করে নিরাপদ সাইন‑আপ/সাইন‑ইন।
- **ইমেইল ভ্যালিডেশন** – সার্ভার‑সাইড ও ক্লায়েন্ট‑সাইডে ইমেইল ফরম্যাট চেক করে, ভ্যালিড না হলে রেজিস্ট্রেশন প্রতিরোধ।
- **রিয়েল‑টাইম চ্যাট** – WebSocket (Vercel Functions) দিয়ে ত্বরিত বার্তা আদান‑প্রদান।
- **শব্দভান্ডার গেম** – ব্যবহারকারীকে কুইজ/ফ্ল্যাশকার্ডের মাধ্যমে নতুন শব্দ শেখায়।
- **ডেটা স্টোরেজ** – Vercel Storage (Edge Config) অথবা MongoDB Atlas‑এ ইউজার প্রোফাইল ও চ্যাট ইতিহাস সংরক্ষণ।
- **ডিপ্লয়মেন্ট** – Vercel‑এ সহজে ডিপ্লয়, preview URL এবং environment variables সহ।

### 🚀 স্ট্যাক
- **ফ্রন্টএন্ড:** Next.js (React) + TailwindCSS
- **বেকএন্ড:** Vercel Functions (Node.js) + Better Auth SDK
- **ডাটাবেস:** MongoDB Atlas (বা Edge Config) 
- **ডিপ্লয়মেন্ট:** Vercel CLI (`vercel`) 

### 📦 রিপো গঠন (প্রস্তাবিত)

│   └─ lib/             # হেল্পার, API ক্লায়েন্ট, auth ইত্যাদি
├─ public/              # স্ট্যাটিক ছবি, আইকন

├─ .gitignore
├─ README.md            # এই ফাইল (প্রোজেক্ট বর্ণনা)

### 📋 পরবর্তী কাজের তালিকা
1. **Git রিমোট সেটআপ** – GitHub/GitLab/Bitbucket এ রেপো তৈরি এবং রিমোট যোগ করা।
2. **README‑আপডেট** – ইনস্টলেশন, ডেভেলপমেন্ট ও ডিপ্লয় গাইড যোগ করা।
3. **.gitignore** – `node_modules/`, `.next/`, `dist/` ইত্যাদি যোগ করা।
4. **Better Auth ইন্টিগ্রেশন** – `utils/validateEmail.ts` এবং auth হুক যুক্ত করা।
5. **ডাটাবেস স্কিমা** – MongoDB collections (`users`, `chats`, `words`) তৈরি।
6. **CI/CD** – GitHub Actions বা Vercel Git Integration দিয়ে স্বয়ংক্রিয় ডিপ্লয় সেটআপ।
